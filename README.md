# 49labs Priority

为 Codex 任务列表添加可见的彩色优先级圆点。选择优先级后，插件会自动重命名当前任务，把标记放在标题最前面：

```text
🔴 修复登录问题
🟠 完成发布文档
🔵 调研新的交互方案
```

## 功能

- 用 `$p0`–`$p6` 快速标记当前 Codex 任务。
- 自动替换已有标记，不会重复叠加圆点。
- 用 `$px` 或 `$pclear` 清除标记。
- 用 `$priority` 打开完整优先级选择提示。
- 保留任务原有标题，只修改标题开头的优先级圆点。

## 快捷指令

| 指令 | 标记 | 含义 |
|---|---|---|
| `$p0` | 🔴 | 紧急 |
| `$p1` | 🟠 | 高 |
| `$p2` | 🟡 | 中 |
| `$p3` | 🟢 | 普通 |
| `$p4` | 🔵 | 低 |
| `$p5` | 🟣 | 有空再做 |
| `$p6` | ⚪ | 暂停 |
| `$px` / `$pclear` | — | 清除标记 |
| `$priority` | — | 显示选择提示 |

## 使用示例

在新的 Codex 任务中输入：

```text
$p1 修复登录问题
```

任务标题会变成：

```text
🟠 修复登录问题
```

如果标题已经是 `🔵 修复登录问题`，再次输入 `$p0` 后会变成 `🔴 修复登录问题`，不会出现多个圆点。

清除标记：

```text
$px
```

## 安装

将插件加入 Codex 可识别的本地 marketplace，然后在 Codex 插件目录中安装。安装或更新插件后，请新建一个任务，以便加载最新技能。

插件包含的主要技能位于 `skills/`，插件清单位于 `.codex-plugin/plugin.json`。

## 工作原理

彩色圆点是任务标题中的 Unicode 字符。技能调用 Codex 的任务标题重命名能力，将对应圆点添加到标题开头，因此它会直接显示在左侧任务列表中。

## 当前限制

- 插件可以自动修改任务和已知子任务的标题。
- Codex 当前没有向插件开放项目文件夹标题的自动重命名接口；项目名称可以在界面中手动改成类似 `🔴 49labs`。
- 更新后的新技能在旧任务中不保证立即可用，建议新建任务测试。
