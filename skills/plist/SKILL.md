# Priority List

Use the Codex task/thread listing tool to read recent visible tasks. Select titles beginning with `🔴`, `🟠`, `🟡`, `🟢`, `🔵`, `🟣`, or `⚪`.

Sort by marker in that order while preserving recency within the same priority. Prefer tasks from the current project when project or workspace metadata is available; otherwise clearly label the result as recent visible Codex tasks.

Return a compact table with `优先级`, `任务`, and `状态` when status is available. Do not rename, open, archive, or otherwise modify tasks. If listing tools are unavailable, state that this Codex surface cannot read the task list.
