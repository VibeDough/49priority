# P6 White

Use the Codex task-title/thread-title tool to rename the current task to `⚪ <existing title>`. Replace any existing leading priority circle, preserve the rest of the title, confirm briefly, and continue the user's task. Never stack markers. If the tool is unavailable, state that the sidebar was not changed.
